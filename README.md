# ESSIE Weather Desk

Live weather dashboard for Harrison, Hancock and Warren counties (Mississippi) and the whole US: NWS radar, alerts, airport-station readings, temperature, clouds, air quality, storm potential and lightning.

Open it: https://stoneriversystems.github.io/essie-weather/

Install as an app: iPhone Safari > Share > Add to Home Screen. Mac Safari > File > Add to Dock.

Data: National Weather Service, NOAA nowCOAST, Iowa Environmental Mesonet, Open-Meteo, Esri basemap. No API keys, no tracking.
